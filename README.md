🗡️ PokeLauncher is a functional app to run games and programs with just a simple APK.
</p>

## Download
You will need a APK for PokeLauncher(base.apk), you can get the apk in the releases.

## ✏️ Permissions
You will need to allow the PokeLauncher APK to access your files in order to run the program you want.

## Tech Stack and Libraries

- Minimum Android SDK: **33**
- [Kotlin](https://kotlinlang.org/) and Kotlin Coroutines(`kotlinx.coroutines`)
